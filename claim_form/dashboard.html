Keselamatan dan data tuntutan

GitHub hanya menyediakan pintu masuk ini. Dashboard sebenar, semakan rekod dan login pegawai dikendalikan oleh Google Apps Script. Admin, OM dan Finance mempunyai tab login sendiri dalam dashboard Apps Script; Audit / Viewer menggunakan OTP. Halaman GitHub tidak menyimpan password atau sesi. Pautan dashboard berfungsi selepas versi Claim V5 yang mengandungi Claim_Dashboard.html dideploy pada URL Apps Script tersebut.
